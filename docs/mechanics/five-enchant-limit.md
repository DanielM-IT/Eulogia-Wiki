# Five-Enchant Limit

Each eligible item may contain no more than **five Eulogia custom enchantments**.

The limit includes:

- shared enchantments;
- item-specific enchantments;
- armour-wide enchantments;
- global enchantments;
- custom curses.

Vanilla enchantments do not consume Eulogia custom-enchantment slots.

## Invalid items

Items that exceed the custom-enchantment limit must not silently function as normal items. Administrator tools can inspect and explicitly repair invalid combinations.
